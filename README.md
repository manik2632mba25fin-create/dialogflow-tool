# Dialogflow Financial Advisor Chatbot

## Overview
This project is a Dialogflow-based Financial Advisor Chatbot designed to help users make informed financial decisions. The chatbot provides guidance on budgeting, loans, insurance, investments, taxes, and financial ratios through conversational AI.

## Features

### Financial Planning
- Budget Advice
- Credit Score Advice
- Tax Saving Advisor
- Insurance Advisor
- Loan Advisor

### Financial Calculations
- ROI (Return on Investment)
- IRR (Internal Rate of Return)
- NPV (Net Present Value)
- Break-even Analysis
- Current Ratio Calculation
- Debt-to-Equity Ratio

### Conversational Support
- Welcome Intent
- Default Fallback Intent
- Financial Query Handling
- Personalized Recommendations

## Technologies Used

- Google Dialogflow
- Natural Language Processing (NLP)
- Intent-Based Conversation Design
- Financial Advisory Knowledge Base
- Kommunicate Integration

## Key Intents

| Intent | Purpose |
|----------|----------|
| Welcome Intent | Greets users |
| Budget Advice | Budget planning recommendations |
| Credit Score Advice | Credit score improvement tips |
| Loan Advisor | Loan-related guidance |
| Insurance Advisor | Insurance recommendations |
| Tax Saving Advisor | Tax optimization suggestions |
| ROI Intent | Return on Investment calculation |
| IRR Intent | Internal Rate of Return calculation |
| NPV Intent | Net Present Value calculation |
| Break-even Intent | Break-even analysis |
| Current Ratio Intent | Liquidity assessment |
| Debt Equity Intent | Financial leverage assessment |

## Setup Instructions

1. Create a Dialogflow Agent.
2. Import or recreate the intents shown in the repository.
3. Configure training phrases and responses.
4. Integrate with Kommunicate (optional).
5. Test the chatbot using Dialogflow Simulator.
